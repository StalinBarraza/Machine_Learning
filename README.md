🚗 Predicción de la gravedad de accidentes de tránsito en Colombia

📌 Descripción del proyecto

Este proyecto se desarrolló como parte de la actividad integradora de Machine Learning, con el propósito de aplicar técnicas de aprendizaje automático para predecir la gravedad de los accidentes de tránsito en Colombia.

Se utilizaron datos abiertos del Registro Único Nacional de Tránsito (RUNT), correspondientes a vehículos involucrados en accidentes de tránsito.

El objetivo es construir un modelo capaz de clasificar los registros en dos categorías:

CON HERIDOS: accidentes que registran personas lesionadas.

CON MUERTOS: accidentes que registran personas fallecidas.

Para facilitar el uso del modelo, se desarrolló una aplicación web utilizando Streamlit, que permite realizar predicciones a partir de las características del vehículo y del accidente.

🎯 Objetivo

Desarrollar un modelo de clasificación mediante Machine Learning que permita estimar la gravedad de un accidente de tránsito utilizando información histórica de vehículos involucrados en siniestros viales en Colombia.

📊 Datos utilizados

El conjunto de datos contiene 450.335 registros y proviene de la plataforma de Datos Abiertos de Colombia.

Entre las variables utilizadas se encuentran:

Marca del vehículo.

Tipo de vehículo.

Departamento del accidente.

Municipio del accidente.

Año del accidente.

Mes del accidente.

Antigüedad del vehículo.

La variable que se busca predecir es la gravedad del accidente, clasificada como CON HERIDOS o CON MUERTOS.
